🚗 TN Smart Car

📌 About the Project

TN Smart Car is a robotics project designed to detect different problems such as waste, road problems, obstacles and streetlight problems. The current design uses Bluetooth for manual control.

⭐ Advantages

  • Helps identify waste
  • Can identify road problems
  • Can detect obstacles
  • Can check streetlight conditions
  • Can be manually controlled using Bluetooth
  • Can be developed further with AI and cloud technology

🔧 Components

  • Arduino UNO
  • HC-05 Bluetooth module
  • Ultrasonic sensor
  • 2 IR sensors
  • LDR
  • LED
  • AFMotor / motor driver
  • 4 DC motors
  • NEO-6M GPS (optional)

🔌 Circuit Diagram

Arduino UNO │ ├── HC-05 Bluetooth │ ├── Ultrasonic Sensor │ ├── TRIG → A0 │ └── ECHO → A1 │ ├── IR Sensor 1 → A2 │ ├── IR Sensor 2 → A3 │ ├── LDR → A5 │ ├── LED → D9 │ └── Motor Driver ├── Motor 1 ├── Motor 2 ├── Motor 3 └── Motor 4

💻 Example Coding

if (obstacleDetected) { Serial.println("STOP"); } if (wasteDetected) { Serial.println("Collect waste"); } if (roadProblemDetected) { Serial.println("Report road problem"); } if (streetlightProblem) { Serial.println("Check streetlight"); }

⚙️ How It Works

The sensors collect information from the surroundings. The Arduino processes the sensor readings and sends the appropriate message. The car remains under manual Bluetooth control.

🗑️ Smart Dustbin

📌 About the Project

The Smart Dustbin is designed to open automatically when a person brings waste near it.

⭐ Advantages

  • Hands-free waste disposal
  • Improves hygiene
  • Easy to use
  • Can reduce unnecessary touching
  • Can be upgraded with waste-level detection

🔧 Components

  • Arduino UNO
  • Ultrasonic sensor
  • Servo motor
  • Dustbin body
  • Jumper wires
  • Power supply

🔌 Circuit Diagram

Ultrasonic ┌───────────┐ │ TRIG ECHO │ └─────┬─────┘ │ ▼ Arduino UNO │ │ Servo Signal ▼ Servo │ ▼ Dustbin Lid

💻 Example Coding

if (distance < 15) { servo.write(90); } else { servo.write(0); }

⚙️ How It Works

The ultrasonic sensor measures the distance of an object near the dustbin. When a person brings waste close to the sensor, the Arduino moves the servo motor and opens the lid.

🧹 Cleaning Robot

📌 About the Project

The Cleaning Robot is a home helper robot concept designed to assist with floor cleaning, waste collection and other household cleaning tasks.

⭐ Advantages

  • Helps with household cleaning
  • Can detect obstacles
  • Can collect waste
  • Can spray water
  • Can be controlled using Bluetooth
  • Can be upgraded with automatic cleaning modes

🔧 Components

  • Arduino UNO
  • L293D motor driver
  • HC-05 Bluetooth
  • Ultrasonic sensor
  • 2 IR sensors
  • Servo motor
  • Water pump
  • Relay module
  • 4 DC motors

🔌 Circuit Diagram

Arduino UNO / | \ / | \ ▼ ▼ ▼ HC-05 Ultrasonic IR Sensors │ │ │ │ ▼ ▼ Bluetooth Obstacle Control Check Arduino │ ▼ L293D Motor Driver / | \ ▼ ▼ ▼ Motor Motor Motor Motor Motor Motor Arduino │ ▼ Relay Module │ ▼ Water Pump Arduino │ ▼ Servo │ ▼ Cleaning Arm

💻 Example Coding

if (obstacleDetected) { stopRobot(); } if (cleaningMode) { startCleaning(); } if (pumpRequired) { digitalWrite(RELAY_PIN, HIGH); }

⚙️ How It Works

The ultrasonic sensor checks for obstacles while the IR sensors can help detect objects or waste. The Arduino controls the motors through the L293D. The relay controls the water pump and the servo can operate a cleaning mechanism.
