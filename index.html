🚗 TN Smart Car

About

TN Smart Car is a manually controlled smart municipal robot. It can detect waste, road problems and streetlight conditions and provide alerts.

Advantages

  • Helps identify waste
  • Can detect road damage
  • Can check streetlight conditions
  • Bluetooth manual control
  • Useful for smart-city concepts

Components

  • Arduino UNO
  • AFMotor / L293D Motor Shield
  • 4 DC Motors
  • HC-05 Bluetooth Module
  • HC-SR04 Ultrasonic Sensor
  • IR Waste Sensor
  • LDR Sensor
  • LED
  • Jumper Wires
  • Robot Chassis

Circuit Connections

TN SMART CAR Arduino UNO │ ├── AFMotor Shield │ ├── M1 → Front Left Motor │ ├── M2 → Front Right Motor │ ├── M3 → Rear Left Motor │ └── M4 → Rear Right Motor │ ├── HC-05 Bluetooth │ ├── TX → D9 │ └── RX ← D10 │ ├── Road Ultrasonic │ ├── TRIG → A0 │ └── ECHO → A1 │ ├── IR Waste Sensor │ └── OUT → A2 │ ├── LDR │ └── AO → A3 │ └── LED └── + → D8

How It Works

The user controls the car through Bluetooth. The motors move according to commands from the Bluetooth controller. The ultrasonic sensor checks the road surface, the IR sensor detects waste and the LDR checks light conditions.

Bluetooth Commands

  • F = Forward
  • B = Backward
  • L = Left
  • R = Right
  • S = Stop

Arduino Code

#include <AFMotor.h> AF_DCMotor motor1(1); AF_DCMotor motor2(2); AF_DCMotor motor3(3); AF_DCMotor motor4(4); #define HC05_RX 9 #define HC05_TX 10 #define TRIG A0 #define ECHO A1 #define WASTE_SENSOR A2 #define LDR_SENSOR A3 #define LED 8 char command; long duration; int distance; void setup() { Serial.begin(9600); pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT); pinMode(WASTE_SENSOR, INPUT); pinMode(LDR_SENSOR, INPUT); pinMode(LED, OUTPUT); stopCar(); Serial.println("TN SMART CAR READY"); } void loop() { if (Serial.available()) { command = Serial.read(); if (command == 'F') { forward(); } else if (command == 'B') { backward(); } else if (command == 'L') { left(); } else if (command == 'R') { right(); } else if (command == 'S') { stopCar(); } } checkRoad(); checkWaste(); checkStreetlight(); delay(100); } void forward() { motor1.setSpeed(180); motor2.setSpeed(180); motor3.setSpeed(180); motor4.setSpeed(180); motor1.run(FORWARD); motor2.run(FORWARD); motor3.run(FORWARD); motor4.run(FORWARD); } void backward() { motor1.setSpeed(180); motor2.setSpeed(180); motor3.setSpeed(180); motor4.setSpeed(180); motor1.run(BACKWARD); motor2.run(BACKWARD); motor3.run(BACKWARD); motor4.run(BACKWARD); } void left() { motor1.run(BACKWARD); motor2.run(FORWARD); motor3.run(BACKWARD); motor4.run(FORWARD); } void right() { motor1.run(FORWARD); motor2.run(BACKWARD); motor3.run(FORWARD); motor4.run(BACKWARD); } void stopCar() { motor1.run(RELEASE); motor2.run(RELEASE); motor3.run(RELEASE); motor4.run(RELEASE); } void checkRoad() { digitalWrite(TRIG, LOW); delayMicroseconds(2); digitalWrite(TRIG, HIGH); delayMicroseconds(10); digitalWrite(TRIG, LOW); duration = pulseIn(ECHO, HIGH, 25000); if (duration > 0) { distance = duration * 0.034 / 2; if (distance < 10) { Serial.println("ROAD DAMAGE DETECTED"); digitalWrite(LED, HIGH); } } } void checkWaste() { int waste = digitalRead(WASTE_SENSOR); if (waste == LOW) { Serial.println("WASTE DETECTED"); digitalWrite(LED, HIGH); } } void checkStreetlight() { int light = analogRead(LDR_SENSOR); if (light < 500) { Serial.println("CHECK STREETLIGHT"); digitalWrite(LED, HIGH); } else { digitalWrite(LED, LOW); } }

🧹 Cleaning Robot

About

The Cleaning Robot is a home helper robot designed to assist with cleaning. It can move using motors, check obstacles, detect waste and operate a water pump for mopping.

Advantages

  • Helps with home cleaning
  • Can detect obstacles
  • Can detect waste
  • Can operate a water pump
  • Can be manually controlled

Components

  • Arduino UNO
  • L293D Motor Driver
  • 4 DC Motors
  • HC-05 Bluetooth
  • Ultrasonic Sensor
  • 2 IR Sensors
  • Servo Motor
  • Water Pump
  • Relay Module
  • Robot Chassis

Circuit Connections

L293D Motor Driver │ ├── Motor 1 ├── Motor 2 ├── Motor 3 └── Motor 4 HC-05 │ ├── TX → Arduino D2 └── RX ← Arduino D13 Ultrasonic │ ├── TRIG → A0 └── ECHO → A1 IR Sensor 1 → A2 IR Sensor 2 → A3 Relay IN → A4 Servo │ ├── Signal → SER1 ├── + → 5V └── - → GND

How It Works

The robot receives manual movement commands through Bluetooth. The ultrasonic sensor checks for obstacles. The IR sensors can detect waste. The servo can be used for a cleaning mechanism and the relay controls the water pump.

Arduino Code

#include <Servo.h> Servo cleaningServo; char command; #define TRIG A0 #define ECHO A1 #define IR1 A2 #define IR2 A3 #define RELAY A4 #define SERVO_PIN 9 void setup() { Serial.begin(9600); pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT); pinMode(IR1, INPUT); pinMode(IR2, INPUT); pinMode(RELAY, OUTPUT); digitalWrite(RELAY, LOW); cleaningServo.attach(SERVO_PIN); cleaningServo.write(90); Serial.println("CLEANING ROBOT READY"); } void loop() { if (Serial.available()) { command = Serial.read(); if (command == 'F') { Serial.println("FORWARD"); } else if (command == 'B') { Serial.println("BACKWARD"); } else if (command == 'L') { Serial.println("LEFT"); } else if (command == 'R') { Serial.println("RIGHT"); } else if (command == 'S') { Serial.println("STOP"); } else if (command == 'W') { digitalWrite(RELAY, HIGH); Serial.println("WATER PUMP ON"); } else if (command == 'X') { digitalWrite(RELAY, LOW); Serial.println("WATER PUMP OFF"); } else if (command == 'C') { cleaningServo.write(30); delay(500); cleaningServo.write(150); delay(500); cleaningServo.write(90); Serial.println("CLEANING ACTION"); } } checkObstacle(); checkWaste(); delay(100); } void checkObstacle() { digitalWrite(TRIG, LOW); delayMicroseconds(2); digitalWrite(TRIG, HIGH); delayMicroseconds(10); digitalWrite(TRIG, LOW); long duration = pulseIn(ECHO, HIGH, 25000); if (duration > 0) { int distance = duration * 0.034 / 2; if (distance < 15) { Serial.println("OBSTACLE DETECTED"); } } } void checkWaste() { if (digitalRead(IR1) == LOW || digitalRead(IR2) == LOW) { Serial.println("WASTE DETECTED"); } }

🗑️ Smart Dustbin

About

The Smart Dustbin automatically opens its lid when someone brings their hand near the sensor.

Advantages

  • Touch-free operation
  • Easy to use
  • Helps maintain cleanliness
  • Simple Arduino project
  • Uses very few components

Components

  • Arduino UNO
  • HC-SR04 Ultrasonic Sensor
  • Servo Motor
  • Dustbin
  • Jumper Wires

Circuit Connections

HC-SR04 VCC → 5V GND → GND TRIG → D7 ECHO → D6 Servo Signal → D9 + → 5V - → GND

How It Works

The ultrasonic sensor continuously measures the distance of an object. When a hand comes close, the Arduino rotates the servo motor and opens the dustbin lid. After a short time the lid closes again.

Arduino Code

#include <Servo.h> Servo lidServo; #define TRIG 7 #define ECHO 6 #define SERVO_PIN 9 void setup() { Serial.begin(9600); pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT); lidServo.attach(SERVO_PIN); lidServo.write(0); } void loop() { long duration; int distance; digitalWrite(TRIG, LOW); delayMicroseconds(2); digitalWrite(TRIG, HIGH); delayMicroseconds(10); digitalWrite(TRIG, LOW); duration = pulseIn(ECHO, HIGH, 25000); if (duration > 0) { distance = duration * 0.034 / 2; Serial.println(distance); if (distance <= 20) { lidServo.write(90); delay(2500); lidServo.write(0); delay(500); } } delay(100); }

🔐 PIR Security System

About

The PIR Security System detects movement and can display the security status on an LCD while using a buzzer to provide an alert.

Advantages

  • Detects human movement
  • LCD displays information
  • Buzzer provides an alert
  • Keypad can be used for control
  • Useful for room security

Components

  • Arduino UNO
  • 16×2 I2C LCD
  • PIR Sensor
  • 4×4 Keypad
  • Buzzer
  • Jumper Wires

Circuit Connections

I2C LCD │ ├── VCC → 5V ├── GND → GND ├── SDA → A4 └── SCL → A5 PIR Sensor │ └── OUT → A0 Buzzer │ └── + → D8 4×4 Keypad Rows: R1 → D4 R2 → D5 R3 → D6 R4 → D7 Columns: C1 → D9 C2 → D10 C3 → D11 C4 → D12

How It Works

The PIR sensor detects movement. When movement is detected, the Arduino displays an alert on the LCD and activates the buzzer. The keypad can be used for additional security controls.

Arduino Code

#include <Wire.h> #include <LiquidCrystal_I2C.h> #include <Keypad.h> LiquidCrystal_I2C lcd(0x27, 16, 2); #define PIR A0 #define BUZZER 8 const byte ROWS = 4; const byte COLS = 4; char keys[ROWS][COLS] = { {'1','2','3','A'}, {'4','5','6','B'}, {'7','8','9','C'}, {'*','0','#','D'} }; byte rowPins[ROWS] = { 4,5,6,7 }; byte colPins[COLS] = { 9,10,11,12 }; Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS); void setup() { pinMode(PIR, INPUT); pinMode(BUZZER, OUTPUT); lcd.init(); lcd.backlight(); lcd.setCursor(0,0); lcd.print("Security System"); lcd.setCursor(0,1); lcd.print("System Ready"); delay(2000); lcd.clear(); } void loop() { int motion = digitalRead(PIR); char key = keypad.getKey(); if (motion == HIGH) { lcd.clear(); lcd.setCursor(0,0); lcd.print("MOTION"); lcd.setCursor(0,1); lcd.print("DETECTED!"); digitalWrite(BUZZER, HIGH); delay(1000); digitalWrite(BUZZER, LOW); } else { lcd.setCursor(0,0); lcd.print("System Normal "); } if (key) { lcd.clear(); lcd.setCursor(0,0); lcd.print("Key: "); lcd.print(key); delay(500); } delay(100); }
